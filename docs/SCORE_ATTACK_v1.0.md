# SCORE ATTACK v1.0

2026-09-30のユーザーによる主モード変更を実装。旧Vertical Slice、UX Pass、最終Sprintの掛け替え仕様に優先する。

## 体験

RUN → WIPE → EVADE → CLIMB。1塔10階、16の独立した窓、18本の設置済み縦ハシゴ・横橋。横枝と戻り道を持つ。窓は足場ごとに得点でき、二枚一組の解除条件を持たない。

横フリックで走る。上下フリックで近くのハシゴを上り下りする。指の速度が移動・登降へ反映される。窓はなぞって拭く。行き先・ハシゴのタップでも移動できる。遠くの窓へ経路全体を自動解決せず、今いる足場か隣接する足場を選ぶ。

ハシゴ選択・設置・回収・運搬・Undoは主モードから除く。時計は経過時間。タイムリミットや強制スクロールはない。カメラは勇者へ追従し、下に戻ることもできる。

骸骨は左右往復、コウモリは上下往復、ゴーストは壁を抜ける左右巡回。3種類・合計6体。周期と初期位相は固定され、ランダムではない。戦闘・HP・ゲームオーバーはない。

窓ふき開始後、勇者は最低1.2秒止まる。敵と時計は動き続ける。最後の細かい汚れは自動仕上げを維持。最上階に着いた瞬間に終了し、Heart Windowを含め全窓CLEANは任意。

## 得点

- 基本点10,000。経過1秒ごとに50点減算。
- 窓1枚CLEANで400点。一枚は一度だけ得点する。
- 敵接触は150点減算（3秒相当）。接触後1.5秒の無敵で連続減点を防ぐ。
- 全16枚CLEANで1,500点ボーナス。
- 最終得点は整数に丸め、最低0点。休止・フォーカス喪失時は時計も巡回も停止。
- TIME / WINDOWS / DAMAGE / SCORE / BESTと即時RETRY。自己ベストは端末に保存。

窓1枚の寄り道が8秒未満なら時間差分では得になる。敵を待つ・避ける時間がルート選択へ影響する。
