# 縦にも、横にも。同じ1本。 — 2026-09-30

## 今回の受け入れ条件

ユーザーの方向指定：ローグライトパズルの面白さを磨く。ハシゴは縦にも、ベランダ間に横にも掛けられる。ハシゴを最大限使い、AHAを大事にする硬派な論理パズルを目指す。

- 1本のハシゴを縦置き・横掛け・回収・再設置に使い回せる。
- 橋のない切れ目は歩いても清掃しても越えられない。
- 窓とフックの鍵が事前に読み取れ、手順を推理できる。
- 間違った順番でも戻れる。現在の城壁だけやり直せる。
- 設置目標は実現可能な最少回数。道具の違いを考慮する。
- マウスとタッチ、720×1280と360×800で3城壁をクリアできる。

## 盤面の考え方

戦闘や反射神経を中心にしない。CLIMB → CLEAN → DISCOVER → OPTIMIZEを保ち、清掃で開く道と1本のハシゴの所在を考える。

| 城壁 | 新しい推論 | 長柄なしの最少設置 | 長柄ありの最少設置 |
|---|---|---:|---:|
| はじまりの城壁 | 磨くと上への道が開く | 2 | 1※ |
| ふたつのベランダ | 縦のハシゴを横の橋へ。帰り道も使う | 4 | 2 |
| 逆算の星あかり塔 | 上下二段の切れ目。E → C → Dの雨戸連鎖 | 6 | 3 |

※最初の城壁では道具をまだ持たない。1回解はルール検証用。

盤面の文字は対応関係を表す。雨戸の「E → C」はEを磨くとCが開く意味。灰色のフックの文字は、その窓を磨くと使えることを示す。「仕掛け」パネルは条件だけを一覧にし、正解手順は出さない。開いている間は時計を止める。

横掛けも縦置きと同じ長さ265のハシゴ。光る↔へ設置し、「わたる」または歩行で渡れる。両端から回収可能。橋の途中で回収を押した場合は、まず安全な岸へ移動する。掛け替え目標を超えても失敗扱いにはしない。

城番号は配置・汚れの種類を再現する。関係を無作為にシャッフルせず、解けるように設計した3種類の盤面の中で位置を変える。Bは左、Cは右という論理上の役割を保つ。

## 道具と再挑戦

城壁1・2のクリア後に未所持の道具を1つ選ぶ。効果は今回のランの終了まで。

- のびるスクイージー：城壁ごとに1枚、一階上の窓を真下付近から磨ける。最初に実際に汚れを落とした窓へ使用枠を予約し、完成で消費。他の高窓へ途中で使い回せない。閉じた雨戸は開けられない。
- おかえりフック：同じ足場から接続しているハシゴをその場で回収。橋上で足場を消すことはできない。
- おすそわけの泡：CLEAN時、同じ階の隣の開いている窓をひと拭き。鍵や雨戸は飛ばせない。

道具順によって最少回数が変わるので、ベスト記録は「城番号＋道具の選択順」で分け、設置回数、その次に徒歩距離で比較する。時間制限はない。同じ城の再挑戦、別の城番号、現在の城壁だけのやり直しを用意。恒久強化・ショップ・戦闘は追加していない。

## 解法を検証して見つかったAHA（ネタバレ）

2枚目＋長柄の最少設置は当初3回と考えたが、独立した状態探索で2回解が見つかった。左から登りBとEを磨いた後、縦のハシゴを残したまま下へ戻ってDを磨く。同じハシゴで再び登ってから横の橋へ使い替え、Cを磨く。回収を急がず、すでにある帰り道を使うことが短縮になる。

3枚目で長柄を選ばない場合は、左から上段へ登る → 横掛けしてEへ → 同じ橋で左へ戻る → 回収して縦に掛けて中段へ降りる → 回収して中段の横橋にする → C → 地上のD。単に橋を何本も増やす問題にしない。
