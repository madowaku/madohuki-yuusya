# ASTRA FINAL SPRINT v1.0 — Jam Shipping Target

## Mission

時間切れまで、窓ふき勇者を **「操作に迷わず、AHAで悩み、最後に塔の頂上へ到達する短編論理パズル」** として完成させる。

Astraはこの文書を最終目標として、下の優先順に自律的に実装・検証する。

最重要原則:

> **操作方法を推理させない。解法だけを推理させる。**

> **プレイヤーの手数は減らす。プレイヤーの思考量は増やす。**

> **常に提出可能なbuildを保つ。**

新機能を思いついても、下の優先順位を飛ばさない。

---

# 1. 最終的なゲーム像

『窓ふき勇者 / WINDOW HERO』はローグライトではない。

**一本のハシゴを縦の梯子・横の橋として使い回し、小さな窓が散らばる高い塔を一階ずつ登る、手作りAHA論理パズル。**

プレイヤーは:

- 足場と窓の配置を読む
- ハシゴをどこに残し、どこへ掛け替えるか考える
- 必要な窓を磨く
- 一部の窓から城内へ入り、内掛け鎧戸を中から開ける
- 開いた経路を利用して上へ進む
- 各階を越えて塔の頂上を目指す

戦闘、ショップ、永続強化、ランダム強化選択は不要。

---

# 2. 感情曲線

1階ごとの理想体験:

1. **見る**
   - 小窓が散らばっている
   - 「あの窓へどう行く？」と思う

2. **考える**
   - ハシゴを縦にするか横にするか
   - 今の橋を残すか移すか
   - 外から行くか室内を通るか

3. **AHA**
   - 「ここで横にすればいい」
   - 「この窓から中へ入れる」
   - 「ハシゴをここに残しておけばいい」

4. **実行**
   - 移動
   - ハシゴ掛け替え
   - CLEAN

5. **報酬**
   - キュッ
   - 暖かい光
   - 新しい通路
   - 住人 / 発見
   - 次の階が見える

6. **上へ**
   - ハシゴを上へ掛ける
   - 勇者が登る
   - 次の階へ

難しさの中心は操作ではなく経路推理。

---

# 3. Shipping Strategy

Astraは以下の順に進める。

各PHASE完了時に:

- tests
- Web export
- itch ZIP
- mouse verification
- touch verification

を更新する。

**後続PHASEが未完成でも、それ以前の状態で提出できるようにする。**

---

# PHASE 0 — SHIP SAFETY

最優先。

- 現在のDraft PR #3のゲームを壊さない
- release Web exportが起動する
- itch ZIPが常に生成できる
- credits / licensesを維持
- runtime warning / error = 0
- main puzzle solver / regression testsを維持

このPHASEは常時条件。

---

# PHASE 1 — UX PASS v0.2 完成

docs/UX_PASS_v0.2.md を実装。

必須:

- [ ] 勇者タップでハシゴ操作を開始する方式を主操作から外す
- [ ] ハシゴそのものをタップして操作
- [ ] 合法配置先をフルサイズのゴーストハシゴで表示
- [ ] 縦 / 横が見た瞬間に分かる
- [ ] 行き先タップで歩行 / 登る / 渡る
- [ ] 通常の「回収」操作を廃止
- [ ] 新しい設置先を選べば必要な回収・運搬は自動
- [ ] 届かない窓をタップした時、無反応にしない
- [ ] 最初に切れている経路 / GAPを短く視覚提示
- [ ] Undo維持
- [ ] Help / “できること表示” は答えを教えず、合法行動だけ見せる

成功基準:

> 初見プレイヤーが「何を押せばいい？」で停止しない。

# PHASE 2 — 3 FLOOR SILENT TUTORIAL

説明文ではなく盤面で教える。

## T1 — VERTICAL

- ハシゴ候補は縦1か所
- 上に汚れ窓1枚
- ladder → ghost → place → climb → CLEAN

## T2 — BRIDGE

- 谷の向こうに窓
- 横候補1か所
- 同じハシゴが橋になることを発見

## T3 — REPOSITION

- 1回目のハシゴ使用後、別位置へ移す必要がある
- Retrieveボタンなし
- ハシゴを再度触って移設

各ステージ:
- 20〜60秒程度
- 長文チュートリアル禁止
- 初回だけ必要なら1〜4語の短い表示まで

例:
- ハシゴをタップ
- 渡れる

それ以上の説明は盤面改善を優先する。

---

# PHASE 3 — THE TOWER

現在の12窓塔を、本編の最初の「本格問題」として磨く。

目標:

- 10〜12小窓
- 1画面
- 1本のハシゴ
- 縦 / 横
- Smart Reposition
- 1つの室内経路
- 1つの内掛け鎧戸
- 1つの恒久ショートカット
- 1つの発見窓
- 最少設置はsolverで検証
- 全合法状態から復帰可能、またはUndo-safe

重要:

**12窓すべてが単なる作業にならないこと。**

通常窓の清掃量は必要なら減らしてよい。

「窓数」より「経路判断」を優先。

---

# PHASE 4 — TOWER ASCENT FLOW

時間が許せば、メニューでステージを切り替える感覚を弱める。

理想:

- 最後の必要窓をCLEAN
- 短い余韻
- 上のフック / 出口が開く
- 勇者がハシゴを掛ける
- 上へ登る
- カメラが上へ
- 次の階が現れる

結果パネルを毎階出さない。

スコア / 最少設置表示は小さくして、流れを止めない。

最低実装としてフェード接続でもよい。

---

# PHASE 5 — FINAL FLOOR / HEART WINDOW

ここが作品の最後の記憶点。

塔の最上階だけに「ボス」がいる。

ただし戦闘しない。

## FINAL PUZZLE

既存ルールのみを組み合わせる。

- 縦梯子
- 横橋
- ハシゴ残置
- 再配置
- 室内経路
- 内掛け鎧戸
- 恒久通路

新しい説明が必要な新ギミックは禁止。

## DEMON KING

魔王は巨大な戦闘ボスではなく、最後の部屋にいる存在。

最終窓:

**HEART WINDOW**

- 通常窓より大きい
- 真っ黒 / 曇っている
- 最後に磨く
- CLEAN後、朝日 / 外の光が入る
- 魔王が少しだけ反応

文章は短く。

候補:
- 「……外って、こんなに明るかったか。」

長い会話イベント不要。

---

# PHASE 6 — ENDING

最終パズル後:

- 城外へ
- 伝説のハシゴ
- 勇者が引き抜く
- ハシゴが上へ伸びる
- 雲を越える

最後に:

**NEXT JOB: THE WINDOWS OF HEAVEN**

短く、笑えて、余韻がある。

時間がなければ1枚絵 + テキストでも成立。

## LADDER

---

# 5. Puzzle Authoring Rules

新ステージを作る場合:

- 1ステージ = 1つの主AHA
- 新ルールではなく既存ルールの組み合わせで難しくする
- 最少設置回数をsolverで検証
- 一本道の手順暗記だけにしない
- 可能なら複数の合法解を許し、最適解にAHAを置く
- 「回収忘れ」「長距離歩き直し」など事務的ペナルティを作らない
- Undoで探索しやすくする
- 窓は小さく、不規則に配置
- 盤面を見て考える時間を作る

---

# 8. Human Acceptance

最終提出前に最低1人の初見プレイヤーで観察。

見るもの:

- 最初に何をタップするか
- ハシゴ操作に迷うか
- 横橋に自力で気づくか
- 届かない窓で何をするか
- 室内で位置を失うか
- 12窓を「作業」ではなく「経路」と見ているか
- AHA後にCLEANが気持ちいいか
- 「もう1階やりたい」が出るか

説明して助ける前に観察する。

---

# 9. Astra Execution Rules

Astraは細かい確認待ちを避け、合理的な判断で進めてよい。

ただし以下は守る:

- gameplay identityを変えない
- 新しい大システムを追加しない
- UXが悪化したらcontentを止める
- solver / tests / Web exportを壊さない
- 警告を放置しない
- mouseとtouchを両方確認
- 重要変更ごとにコミット
- 各PHASE後に提出可能ZIPを更新
- 既存の生成素材 / credits / licensesを維持
- 最終的な操作説明は極力減らす

迷った場合の判断順:

1. 初見で分かるか
2. パズルとして面白いか
3. 操作が気持ちいいか
4. 絵として分かるか
5. 実装量が少ないか

---

# 10. Do Not Build

時間切れまで禁止:

- ローグライト化
- ランダム生成ラン
- ショップ
- 永続アップグレード
- 戦闘システム
- 敵AI
- アイテム大量追加
- インベントリ
- 複雑な会話
- 室内迷路
- 箱押し
- 装備システム
- 複数ハシゴ管理
- 3D化
- 大規模アート刷新

- [ ] touch完走

- [ ] itch ZIP integrity OK
