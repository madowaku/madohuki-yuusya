# Vertical Slice v0.1

## Goal

この30秒が「もう1枚拭きたい」と思えるかだけを検証する。

```
ハシゴを持つ
→ 掛ける
→ 登る
→ 汚れた窓を擦る
→ 最後の汚れが落ちる
→ キュッ！✨
→ 窓が透明になる
→ 中の住人/仕掛けが見える
→ 次の窓へ行きたくなる
```

## Scope

1画面の小さな城壁。

- 勇者 1体
- ハシゴ 1本
- 設置ポイント 3-4か所
- 窓 5枚
- 通常窓 3
- 住人窓 1
- 仕掛け窓 1
- ゴール 1

この初期スライスの検証範囲では、ローグライト、ショップ、メタ進行、複数城は入れない。受け入れ確認後の拡張は `LADDER_PUZZLE_v0.2.md` に分けて記録する。

## Required Interactions

### Hero
- 左右移動
- ハシゴを持つ
- ハシゴを置く
- ハシゴを登る/降りる

### Ladder
- 設置候補を明示
- 不正配置を拒否
- 回収可能
- 長さは固定

### Window
- DIRTY 100% から開始
- マウスドラッグとタッチドラッグで汚れを削る
- 汚れ量に応じて見た目が変わる
- 0%で CLEAN
- CLEAN時に短いSE、光、軽い画面反応
- CLEAN後に窓の奥を表示

## First Puzzle

### Setup

- 地上から届く窓 A
- Aを磨くと「上部フック」が有効になる
- ハシゴを掛け直して上階へ
- 上階で窓 B / C を清掃
- Cの中の住人が最終窓への足場を出す
- 最終窓を磨くと CLEAR

### Intended Realization

「窓を拭くことが、次の移動手段を開く」

## Feel Targets

### Ladder Place
置いた瞬間に「ガシャン」と重さを感じる。

### Climb
遅すぎず速すぎず。3-4秒で1本を登れる。

### Cleaning
2-4秒で1枚。短すぎて作業感を失わず、長すぎて面倒にならない。

### Final Dirt
最後の5%は視認しやすくする。Pixel Huntにしない。

### Reveal
透明化は0.2-0.4秒程度の気持ちいい切り替え。

## Acceptance Criteria

- [x] 720x1280で全操作可能
- [x] マウスとタッチ両対応
- [x] ハシゴ配置場所が初見で分かる
- [x] 1回も説明文を読まずに最初の窓を拭ける
- [x] 窓1枚の清掃が2-4秒程度
- [x] CLEAN瞬間に音と視覚の報酬がある
- [x] 窓を磨いた結果、次の行動が変化する
- [x] 5枚を3分以内にクリア可能
- [x] リスタート可能
- [x] Web Exportで動作

2026-09-29: 操作・進行・Web出力を自動検証済み。マウスとCDPのタッチ入力で全5枚をクリア。ユーザーは「最初の窓ふきとハシゴの設置場所は、説明文を読まずに分かったか」に **「両方とも分かった」** と回答。これで初期スライスの受け入れ項目を満たした。楽しさ・AHAの強さは引き続き人の試遊で確かめる。ユーザーからローグライトおよび縦横ハシゴの論理パズル拡張を明示的に依頼され、次段階へ進む。

## Kill Criteria

次のどれかならコンテンツ追加を止めてコアを直す。

- ハシゴ設置が面倒
- 登る時間が退屈
- 窓ふきがただの作業
- 汚れ残りが見つからずイライラする
- Revealが嬉しくない
- 次の窓へ行きたいと思わない
